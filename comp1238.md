## Week 1 - History
- Writing systems were used to record information.
- Typewriters influenced the QWERTY keyboard layout.

## Week 2 - Bits and Bytes
- A bit can be 0 or 1.
- One byte contains 8 bits.

## Week 3 - Text Structure
- Markdown and HTML are markup languages.
- JSON and XML store structured data.

## Week 4 - Working With Text
- Text editors include Notepad, vi, and VS Code.
- Regular expressions help search for text patterns.

## Week 5 - Command Line
- `ls` lists files; `pwd` shows the current directory.
- SSH allows remote access, while `scp` transfers files.
